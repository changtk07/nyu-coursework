# Artificial Intelligence (NYU CSCI-GA.2560, Fall 2021)

Four labs for Artificial Intelligence, NYU Fall 2021, all written in C++.

## Contents

| Folder | Topic | Spec |
| --- | --- | --- |

| [`lab3`](lab3/) | Markov decision process solver: value iteration and greedy policy computation | [lab3](https://cs.nyu.edu/courses/fall21/CSCI-GA.2560-001/lab3.html) |
| [`lab4`](lab4/) | Machine learning: k-nearest neighbors and k-means clustering | [lab4](https://cs.nyu.edu/courses/fall21/CSCI-GA.2560-001/lab4.html) |
